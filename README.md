# imigracao-uruguai-os-marketplace

Marketplace oficial do plugin **imigracao-uruguai-os** (IA Combativa).

## O que é

Sistema operacional de imigração para o **Uruguai** — 3 frentes (imigrante · comercial · advogado). 40 skills, Ley 18.250, gates de vigência e de representação (início pessoal na DNM; OAB ≠ advocacia UY).

## Instalação (Claude Cowork / Claude Code)

1. Abra **Settings → Plugins**
2. Aba **Pessoal** → **+** (Uploads locais / Add marketplace)
3. Cole a URL deste repositório GitHub
4. Instale o plugin `imigracao-uruguai-os`
5. Rode `/start-imigracao-uruguai` e depois `/imigracao-uruguai`

## Aviso

Este plugin **não substitui** profissional habilitado no Uruguai. Não garante residência, cédula, Carta ou passaporte.

O repositório é público para viabilizar a instalação. **Não é software livre** — o direito de uso é concedido pela compra (Kirvano). Ver `LICENSE`.
